# 🚀 Muhammad Musa Khan - Developer Portfolio

A modern and responsive **Next.js portfolio website** built using **TypeScript, Tailwind CSS, and Framer Motion**.  
Showcases my **skills, projects, and experience** with beautiful animations and a clean dark UI.

---

## ✨ Features
- 🧑‍💻 Fully responsive and modern design  
- 🎨 Animated sections powered by **Framer Motion**  
- 💼 Projects, skills, and contact sections  
- ⚡ Fast performance with **Next.js 15**  
- 🌙 Elegant dark theme with glass effects  

---

## 🛠️ Tech Stack
**Frontend:** Next.js, React, TypeScript  
**Styling:** Tailwind CSS, Shadcn/UI, Framer Motion  
**Tools:** Git, Vercel, VS Code
